¿Cómo consigo esto?
Client ID (una vez):
  1. Ve a console.cloud.google.com y crea un proyecto.
  2. En "APIs y servicios" → habilita Google Drive API.
  3. En "Pantalla de consentimiento OAuth" → tipo Externo → modo Testing → añade tu email como usuario de prueba (así no necesitas verificación de Google).
  4. En "Credenciales" → crear ID de cliente de OAuth → tipo "Aplicación web".
  5. En "Orígenes de JavaScript autorizados" añade la URL exacta donde alojes este archivo (ver nota abajo).
  6. Copia el Client ID generado y pégalo arriba.
ID de la carpeta: abre la carpeta de Drive del Kobo en el navegador y copia el trozo de la URL después de /folders/.

Importante: este archivo debe alojarse en una URL fija (por ejemplo GitHub Pages, gratis) para que Google acepte el origen. Si lo abres suelto desde el móvil sin alojarlo, "Conectar Google Drive" no funcionará — igual puedes usar el conversor y descargar el archivo a mano.
